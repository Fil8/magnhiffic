Sample List

The table below lists the 33 active galaxies observed by MAGNHIFFIC. An ascii version of this table is also available. Each object name links to its entry in the NASA/IPAC Extragalactic Database. 

Column densities and distances assume H0 = 67.8 km s−1 Mpc−1. AGN types distinguish radiative-mode (Seyfert) sources from radio-jetted (RL) sources; the environment column gives the group or cluster membership of the host. 

The sample is made of two main subsamples — the MAGNUM galaxies and the radio-loud sources — plus additional sources.
